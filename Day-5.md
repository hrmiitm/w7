## Day-5 Checklist

- [ ] I have configured Git with `git config --global user.name`, `user.email`, and `init.defaultBranch main`
- [x] I know GitHub allows only one account per person and have merged IITM + personal accounts
- [ ] I understand the three states: working tree → staging → committed
- [x] I can run `git status`, `git diff`, and `git log` and know what each shows
- [ ] I know how `.gitignore` works and how to ignore `venv`, `__pycache__`, `.env`
- [ ] I can make a commit: `git add` → `git commit -m "message"` → `git push`
- [ ] I know what `origin` and `main` are and can explain each in one sentence
- [ ] I can set up SSH key authentication and push to GitHub without a password
- [ ] I can create an annotated tag (`git tag -a v0.1.0`) and push it to GitHub
- [ ] I can write a meaningful commit message (not "fixed stuff" or "final.py")
